# Setu: Study ka saathi 📚

Setu ek study companion app hai jo Class 10, 11 aur 12 ke students ko apni **padhai, samay aur sehat** ek hi jagah sambhalne me madad karta hai.

Maharashtra Board (SSC/HSC), MHT-CET aur NDA jaise exams ki taiyari ke liye bana hai. Sab data aapke phone me hi rehta hai.

## ⬇️ Download
[**Releases**](../../releases) section me jao aur **Setu.apk** download karo.

### Install kaise kare
1. Setu.apk apne Android phone me download karo
2. Agar phone puchhe to "Install from unknown sources" allow karo
3. File kholo aur install karo

## ✨ Features

### 📖 Padhai
- **Study Tracker:** subject → chapter → topic ke hisaab se syllabus. Lecture, Reading, Exercise, PYQ aur Revision tick karo, progress % dekho. Apna subject, chapter aur subtopic bhi jod sakte ho.
- **Study Log:** kitna time lagaya, clock selector, stopwatch ya countdown se darj karo. Countdown khatam hote hi alarm.
- **Focus Timer (Pomodoro):** status bar me countdown aur alarm ringtone.
- **Vedic Maths:** 16 mukhya aur 13 upa-sutra, Hinglish samjhaav aur solved examples ke saath.
- **Notes:** text, photo, video aur file. PDF ya text me download.
- **Previous Year Papers:** Class 10 aur 12 board papers ke links.

### ⏰ Samay aur Reminder
- Shift Schedule, Weekly, Monthly, Yearly aur Calendar
- Smart reminders: din se pehle, event wale din subah, aakhri 5 minute me countdown, time par alarm
- Birthday wish, Aaj ke tasks (time slot ke saath)

### 💪 Sehat aur Aadat
- Paani, neend, exercise aur running tracker, saath me goals
- Goal popup (jaise NDA): "Bhai, NDA ki tayari kaisi chal rhi hai?"
- History: app me kya badla, sab dikhta hai

### 👥 Dost aur Chat (naya)
- ID banao, follow/follow back, chat, 24 ghante wale Instants
- Cloud backup se kisi bhi phone par data wapas
- Iske liye ek alag server chalana padta hai
